# 🚀 WebCodeAnalyzer

منصة سحابية ذكية ومتطورة مبنية بتقنيات **Blazor Interactive Server** و **.NET** للتحليل الاستاتيكي المعمق لبنية ملفات الويب. تهدف المنصة إلى سبر أغوار الشيفرات البرمجية واكتشاف الأكواد الميتة (Dead Code) والعناصر غير المستخدمة وتطهيرها لرفع كفاءة الأداء وتقليص أحجام المشاريع بالبكسل.

---

## 💡 عن المنصة
عند بناء واجهات الويب، تتراكم الكثير من كلاسات الـ CSS والدوال البرمجية في ملفات الـ JavaScript دون استخدام فعلي، مما يزيد من حجم النقل السحابي ويبطئ المتصفح. **WebCodeAnalyzer** يحل هذه المشكلة عبر محرك فحص ذكي يربط العلاقات المتبادلة بين الملفات الثلاثة ويقنص الهدر بدقة متناهية.

---

## ✨ الميزات الرئيسية (Core Features)

* **📁 معالجة المجلدات الذكية (Folder Streaming):** دعم كامل لسحب وإفلات مجلد المشروع بالكامل (`webkitdirectory`) وقراءة هياكله بشكل تراكمي فوري.
* **📄 التجميع التتابعي للملفات:** إمكانية رفع ملفات منفردة متتابعة دون مسح الملفات السابقة، مما يتيح فحص واستيراد ملفات من مجلدات فرعية مختلفة.
* **📊 لوحة تحكم عصرية (Modern Flat Dashboard):** جداول نتائج مريحة جداً للعين بمؤشرات بصرية وأيقونية تفاعلية تعتمد على حالة الكود (نشط وعامل / ميت 💀).
* **⚡ الفرز الفلكي السريع بمحرك LINQ:** إمكانية نقر هيدر الجدول لعمل ترتيب فوري ودفع كافة الأكواد والدوال المهملة إلى الخطوط الأمامية للجدول بلمح البصر.
* **📈 المؤشرات المتقدمة للأداء (Advanced Metrics Modals):** نوافذ منبثقة لحساب حجم الملف الأصلي، وحجم النقل المضغوط عبر حزم **Gzip**، مع حساب دقيق لنسبة الهدر المئوية.
* **🔊 حركية انسيابية (Perceived Performance UX):** تمرير تلقائي رياضي دقيق يعتمد على الإحداثيات المطلقة للشاشة للتمركز فوق النتائج فور انتهاء الفحص التكتيكي وتغيير نصوص الأزرار لتفاعل حيوي مع المستخدم.

## 🛠️ البنية التحتية والتقنيات (Tech Stack)

* **Backend Logic:** C# , .NET 
* **UI Framework:** Blazor (InteractiveServer Mode)
* **Design & Icons:** Bootstrap 5 & Bootstrap Icons
* **Animations:** Animate.css 
* **Scripts:** JavaScript

## 🤝 مجتمع المطورين والمساهمة (Feedback & Bug Tracking)

هذا المستودع (Repository) هو **الواجهة المجتمعية الرسمية** لمنصة **WebCodeAnalyzer**. بهدف حماية الملكية الفكرية (Intellectual Property) والمسارات الاستثمارية للمشروع، فإن **الشيفرة البرمجية المخرجة (Source Code) مغلقة ومحفوظة بشكل مشفر في مستودع خاص**.

ومع ذلك، نحن نؤمن بقوة ومجتمع المطورين في الارتقاء بجودة وأداء البرمجيات؛ لذا تم فتح وتخصيص هذه المساحة العامة بالكامل لاستقبال بلاغات الأخطاء والمقترحات الهندسية لتحديث المنصة السحابية الحية:

* **🪲 تعقب الأخطاء (Bug Tracking):** إذا واجهت أي كراش برمي، ومضة ألوان عشوائية، أو سلوك غير متوقع أثناء فحص مشاريعك، قُم بفتح **Issue** واشرح المشكلة بكسليّاً.
* **💡 الاقتراحات والميزات الذكية:** هل لديك رؤية معمارية مخصصة أو فكرة خوارزمية ذكية تطمح لحقنها في محرك الفحص الاستاتيكي؟ شاركنا تفاصيلها هنا.
